# 추연승 이력서

프로필, 자기소개, 연락처, 기술 스킬, 프로젝트로 구성된 온라인 이력서 페이지입니다.

## 구성
- `index.html` — 이력서 본문 (My info / About / Contact / Skills / Projects)
- `css/style.css` — 스타일시트 (Noto Sans KR 웹폰트 사용)
- `images/` — 프로필 사진 및 연락처 아이콘(전화, 이메일, 페이스북, 블로그)
- `movement.mp4` — 자작차 작동 영상

## 기술 스택
- HTML5, CSS3 (Google Fonts)

## 실행 방법
`index.html`을 브라우저로 열면 바로 확인할 수 있습니다.
