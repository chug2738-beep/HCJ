## 프로젝트 목록

- **[0723](0723/)** — 추연승 엔지니어링(CAE) 포트폴리오. CATIA/Abaqus/STAR-CCM+ 프로젝트를 소개하는 단일 HTML 페이지.
- **[0724](0724/)** — 추연승 이력서 페이지. 프로필, 소개, 연락처, 스킬, 프로젝트 섹션으로 구성된 이력서.
- **[0727](0727/)** — 포트폴리오 실습(템플릿). 주혜린(HyeRrin)님 포트폴리오를 참고해 만든 반응형 포트폴리오.
- **[0730](0730/)** — 추연승 개인 포트폴리오. `0727` 템플릿을 본인 정보로 커스터마이징한 버전.
- **[0831](0831/)** — 서울 3박4일 여행 코스 웹앱(Google Apps Script). 일본인 여행자 대상 일정 안내 페이지.
- **[0901](0901/)** — 일본 여행지 선정 설문 웹앱(Google Apps Script). 응답을 구글 스프레드시트에 저장.
- **[0907](0907/)** — `antigpt/` K-TRIP KOREA 관광 가이드. 일본인 대상 한국 공식 관광 가이드 웹페이지(Tailwind CSS + jQuery).

각 프로젝트 폴더에는 세부 내용을 담은 `README.md`가 있습니다.
