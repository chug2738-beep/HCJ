# 🔮 속성 기반 오늘의 운세 서비스

사용자 정보(이름, 생년월일, 성별)와 선택한 속성(불, 물, 나무, 땅, 바람)을 기반으로 랜덤 오늘의 운세를 보여주는 간단한 웹 애플리케이션입니다.

---

## 🛠️ 사용 기술
- **HTML5**: 웹 페이지 구조 작성
- **CSS3**: 반응형 카드 UI 및 애니메이션 스타일링
- **JavaScript (ES6)**: 속성 선택 및 무작위 운세 로직 구현

---

## 🚀 Visual Studio에서 실행하는 방법

### 방법 1: Visual Studio (Community / Professional 등) 사용 시
1. Visual Studio를 실행하고 **[HTML 페이지가 포함된 새 프로젝트]** 또는 **[빈 프로젝트]**를 생성합니다.
2. 프로젝트 내에 `index.html` 및 `README.md` 파일을 생성하고 코드를 붙여넣습니다.
3. `index.html` 파일을 마우스 우클릭한 후 **[브라우저에서 보기 (Ctrl + Shift + W)]**를 클릭합니다.

### 방법 2: Visual Studio Code (VS Code) 사용 시
1. 폴더를 연 뒤 `index.html` 및 `README.md` 파일이 존재하는지 확인합니다.
2. 확장 기능(Extensions) 탭에서 **Live Server**를 설치합니다.
3. `index.html` 파일에서 우클릭 후 **[Open with Live Server]**를 선택하여 실행합니다.

---

## ✨ 주요 기능
- **사용자 정보 입력**: 이름, 생년월일, 성별 입력
- **속성 선택**: 불, 물, 나무, 땅, 바람 5가지 속성 중 선택 가능
- **오늘의 운세 생성**: 선택한 속성에 맞춤화된 운세 문구 및 행운 지수(70~100점) 랜덤 도출
- **초기화 기능**: '다시 하기' 버튼을 통한 재시도 가능
