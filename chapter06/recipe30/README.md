# 🎰 서바이벌 구슬 추첨기 (Marble Survival Raffle)

참가자들의 이름을 대포에서 구슬로 연달아 발사한 뒤, 장애물(파친코/핀볼 구조)을 헤쳐 나가 **가장 마지막에 도착하는 구슬을 당첨자**로 선정하는 물리 엔터테인먼트 추첨 앱입니다.

---

## ✨ 주요 특징
- **2D 자체 물리 엔진**:
  - 중력, 마찰력, 장애물(Peg)과의 정교한 반사각 충돌 계산
  - 구슬 끼임 방지 로직 적용
- **서바이벌 당첨 규칙**:
  - 일찍 떨어진 구슬은 탈락! **가장 늦게 떨어진 느림보 구슬이 최종 당첨**
- **실시간 리더보드**:
  - 몇 번째로 구슬이 통과했는지 순위 실시간 렌더링
- **대포 연속 발사**:
  - 일정 간격으로 구슬이 대포에서 튀어나오는 다이내믹한 애니메이션

---

## 🛠️ 사용 기술
- **HTML5 Canvas**: 2D 물리 연산 및 프레임 기반 렌더링 (`requestAnimationFrame`)
- **CSS3**: 아케이드 모던 테마 UI & 승자 발표 팝업 모달
- **JavaScript**: 벡터 반사각 수학 연산 및 상태 관리

---

## 🚀 Visual Studio 실행 방법

1. 프로젝트 폴더 내에 `index.html`과 `README.md`를 준비합니다.
2. `index.html`을 우클릭 후 **[브라우저에서 보기]** (또는 VS Code **Live Server**)로 실행합니다.
3. 참가자 이름을 입력하고 **[🚀 대포 발사!]** 버튼을 클릭합니다.
