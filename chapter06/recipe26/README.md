# 📜 실시간 Lorem Ipsum 생성기

슬라이더를 이용하여 원하는 분량의 더미 텍스트(Lorem Ipsum)를 실시간으로 생성할 수 있는 웹 애플리케이션입니다.

---

## ✨ 주요 기능
- **실시간 길이 조절**: 슬라이드 바 이동 시 즉시 더미 텍스트 분량 업데이트
- **길이 범주 설정**: 최소 **10자** ~ 최대 **5,000자** (기본 **150자**)
- **자주 쓰는 프리셋 버튼**: 50자, 150자, 500자, 1,000자, 5,000자 원클릭 적용
- **원클릭 클립보드 복사**: 생성된 텍스트를 버튼 클릭 한 번으로 간편하게 복사

---

## 🛠️ 사용 기술
- **HTML5**: 구조 작성 및 시맨틱 UI
- **CSS3**: 반응형 디자인 및 슬라이더 스타일링
- **JavaScript**: 실시간 텍스트 생성 알고리즘 및 클립보드 API

---

## 🚀 Visual Studio 실행 방법

1. Visual Studio에서 프로젝트 폴더를 엽니다.
2. `index.html`과 `README.md` 파일이 프로젝트 내에 배치되어 있는지 확인합니다.
3. `index.html`을 우클릭한 후 **[브라우저에서 보기]** (또는 VS Code의 경우 **Live Server**)로 실행합니다.
