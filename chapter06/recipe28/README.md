# 🚶 자리 비움 알림이 (Away Screen Display)

잠시 자리를 비울 때 모니터 화면에 **일정(부재 사유), 복귀 예정 시간, 카운트다운, 연락처 및 기타 안내 문구**를 시각적으로 보여주는 전용 화면 표시 앱입니다.

---

## ✨ 주요 특징
- **부재 사유 극대화**: 일정(부재 사유)을 화면에서 가장 크게 강조하여 멀리서도 한눈에 확인 가능
- **실시간 카운트다운**: 복귀 시각까지 남은 시간을 분/초 단위로 지속 업데이트
- **화려한 그라데이션 애니메이션**: 부드럽게 넘실거리는 무지개빛 그라데이션 배경 및 글래스모피즘 UI
- **편의 기능**:
  - 기본 복귀 시간을 자동으로 **+30분** 설정
  - `ESC` 키 입력으로 손쉽게 설정 수정 화면으로 복귀

---

## 🛠️ 사용 기술
- **HTML5**: Form 및 전체 화면 알림 구조
- **CSS3**: `backdrop-filter`(글래스모피즘), Keyframe 애니메이션, `clamp()` 가변 폰트
- **JavaScript (ES6)**: `Date` 타임스탬프 계산 및 `setInterval` 실시간 타이머 연산

---

## 🚀 Visual Studio 실행 방법

1. 프로젝트 폴더를 열고 `index.html`과 `README.md`를 준비합니다.
2. `index.html` 우클릭 후 **[브라우저에서 보기]** (또는 VS Code **Live Server**)로 실행합니다.
3. 일정과 복귀 시간을 확인한 뒤 **[자리 비움 화면 켜기]**를 클릭합니다.
