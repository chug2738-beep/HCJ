# ⚖️ BMI & 목표 체중 계산기

신장, 체중, 성별을 기반으로 **BMI(체질량지수)**를 연산하고, **BMI 90%, 100%(표준), 110%**에 도달하기 위해 조절해야 하는 목표 체중(kg)을 제시해 주는 건강 관리 웹 애플리케이션입니다.

---

## ✨ 주요 기능
- **성별 맞춤 BMI 계산**: 남성(표준 BMI 22) 및 여성(표준 BMI 21) 기준 분리 적용
- **비만도 판정**: 대한비만학회 기준(저체중, 정상, 과체중, 비만) 시각화 배지 제공
- **목표 체중 조절량 제시**:
  - **BMI 90%**: 슬림/미용 체중 대비 필요 감량/증량 kg
  - **BMI 100%**: 표준 체중 대비 필요 감량/증량 kg
  - **BMI 110%**: 과체중 경계 체중 대비 필요 감량/증량 kg

---

## 🛠️ 사용 기술
- **HTML5**: 신체 수치 입력 폼 및 결과 컨테이너 구성
- **CSS3**: 반응형 카드 레이아웃 및 상태별 컬러 코딩
- **JavaScript**: 표준 체중 공식을 이용한 목표 감량/증량 수치 연산

---

## 🚀 Visual Studio 실행 방법

1. 프로젝트 폴더 내에 `index.html`과 `README.md`를 준비합니다.
2. `index.html`을 우클릭 후 **[브라우저에서 보기]** (또는 VS Code **Live Server**)로 실행합니다.
3. 성별, 키, 몸무게를 입력하고 **[계산]** 버튼을 누릅니다.
