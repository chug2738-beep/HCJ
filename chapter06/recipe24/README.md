# 📝 실시간 글자 수 & 바이트(Byte) 계산기

사용자가 입력한 텍스트의 글자 수와 바이트(Byte) 용량을 실시간으로 측정해 주는 웹 애플리케이션입니다.

---

## ✨ 핵심 특징
- **한글 2 Byte 계산 법칙 적용**: 
  - 한글, 한자, 특수문자 등: **2 Byte**
  - 영문, 숫자, 공백, 줄바꿈 등: **1 Byte**
- **4가지 측정 결과 제공**:
  1. 공백 포함 글자 수
  2. 공백 제외 글자 수
  3. 공백 포함 용량 (Byte)
  4. 공백 제외 용량 (Byte)
- **편의 기능**: 입력 텍스트 전체 복사 기능 및 한 번에 비우기 버튼 제공

---

## 🛠️ 사용 기술
- **HTML5**: 웹 레이아웃 구성
- **CSS3**: 반응형 웹 디자인 및 그리드 레이아웃
- **JavaScript**: 실시간 바이트 연산 (Unicode CharCode 판별)

---

## 🚀 Visual Studio 실행 방법

1. Visual Studio에서 프로젝트 폴더를 엽니다.
2. 폴더 내에 `index.html`과 `README.md` 파일을 배치합니다.
3. `index.html`을 우클릭하고 **[브라우저에서 보기]** (또는 VS Code의 경우 **Live Server**)로 실행합니다.
