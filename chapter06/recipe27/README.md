# 🧩 PDF 파일 병합기 (PDF Merger)

여러 개의 PDF 문서를 하나의 PDF 파일로 합쳐주는 순수 프론트엔드 웹 애플리케이션입니다.

---

## ✨ 핵심 기능
- **다중 PDF 업로드**: 여러 개의 PDF 문서를 한 번에 추가 가능
- **순서 변경 기능**: 위/아래(`▲`/`▼`) 버튼을 사용하여 병합할 문서의 순서 자유롭게 배치
- **보안성**: 서버로 파일이 업로드되지 않고, 사용자의 웹 브라우저 메모리 상에서 안전하게 처리
- **자동 다운로드**: 병합 완료 후 자동으로 하나로 합쳐진 PDF 파일 다운로드 제공

---

## 🛠️ 사용 기술
- **HTML5**: UI 구조 및 파일 입력 API
- **CSS3**: 반응형 카드 및 파일 목록 스타일링
- **JavaScript (ES6+)**: `async/await`, `ArrayBuffer`, `Blob`
- **[pdf-lib](https://pdf-lib.js.org/)**: 브라우저 기반 PDF 생성 및 페이지 병합 라이브러리

---

## 🚀 Visual Studio 실행 방법

1. Visual Studio에서 프로젝트 폴더를 작성하고 `index.html`과 `README.md`를 추가합니다.
2. `index.html`을 마우스 우클릭 후 **[브라우저에서 보기]** (또는 VS Code의 **Live Server**)로 실행합니다.
3. PDF 파일들을 업로드한 뒤 순서를 조정하고 **[PDF 병합 및 다운로드]** 버튼을 누릅니다.
