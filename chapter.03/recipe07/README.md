# Smart Image Resizer (스마트 이미지 리사이저)

Smart Image Resizer는 사용자가 업로드한 이미지를 별도의 백엔드 서버 전송 없이, 순수 웹 브라우저의 HTML5 Canvas API를 통해 다양한 종횡비(1:1, 3:4, 4:3, 9:16, 16:9, 커스텀)에 맞추어 변환하고 패딩(Padding) 또는 크롭(Crop) 처리를 수행하는 고성능 클라이언트 사이드 웹 애플리케이션입니다.

---

## 1. 주요 기능 및 요구사항 반영

1. 상단 로고 및 외부 연동:
   - 좌측 상단에 `logo.png` 로고가 배치되어 있으며, 로고 클릭 시 공식 웹사이트(https://nanalab.kr)로 이동합니다.
2. 서비스 타이틀 표기:
   - 우측 상단에 "Smart Image Resizer"가 배치되어 서비스 목적을 직관적으로 제공합니다.
3. 드래그 앤 드롭 및 파일 탐색기 업로드 지원:
   - 메인 화면 중앙의 드롭 존에 이미지 파일을 직접 끌어다 놓거나 "파일 선택하기" 버튼을 클릭하여 다중 이미지를 업로드할 수 있습니다.
4. 유연한 캔버스 종횡비(Aspect Ratio) 선택:
   - 프리셋 비율(1:1, 3:4, 4:3, 9:16, 16:9) 버튼을 지원합니다.
   - "Custom" 선택 시 원하는 가로(W)와 세로(H) 비율을 직접 정밀 입력할 수 있습니다.
5. 변환 방식(Mode) 선택:
   - 사용자는 Padding(여백 채우기) 모드와 Crop(중앙 잘라내기) 모드 중 원하는 방식을 선택할 수 있습니다.
6. 스마트 패딩(Padding) 및 배경색 제어:
   - 사진의 원본 종횡비와 목표 캔버스 비율이 일치하지 않을 때, 사진 축소/왜곡 없이 여백을 두어 크기를 맞춥니다.
   - 여백 색상은 기본 흰색(#FFFFFF)이며, 컬러 피커 또는 프리셋 팔레트(화이트, 블랙, 그레이, 슬레이트, 베이지)를 통해 자유롭게 변경할 수 있습니다.
7. 스마트 크롭(Crop) 처리:
   - Crop 선택 시 종횡비에 맞게 사진의 중앙을 중심으로 불필요한 영역을 잘라내어 캔버스를 꽉 채웁니다.
8. 다중 이미지 대기열 및 썸네일 목록:
   - 여러 장의 이미지를 동시에 업로드하면 각 파일의 썸네일, 파일명, 규격 정보가 리스트 형태로 즉시 생성됩니다.
9. 실시간 단계별 프로그레스 바:
   - 각 썸네일 우측에 프로그레스 바가 위치하며, 이미지 로딩 -> 비율 연산 -> 캔버스 렌더링 -> Blob 인코딩 단계에 맞춰 실시간으로 부드럽게 차오릅니다.
10. 개별 다운로드 버튼 활성화:
    - 각 파일의 프로그레스 바가 100%에 도달하면 다운로드 버튼이 활성화되어 변환된 단일 이미지를 즉시 다운로드할 수 있습니다.
11. 일괄 압축 다운로드 (ZIP):
    - 대기열의 모든 이미지 처리가 100% 완료되면 "일괄 다운로드 (ZIP)" 버튼이 활성화되며, 클릭 시 모든 결과물이 단일 ZIP 파일(`smart_resized_images.zip`)로 일괄 패키징되어 저장됩니다.

## 2. 기술 스택

- Markup: HTML5 (시맨틱 웹 표준 규격 준수)
- Styling: CSS3 (CSS Custom Properties, Flexbox, CSS Grid, 글래스모피즘) + Tailwind CSS CDN 호환
- Scripting: Modern JavaScript (ES6+, Async/Await, Canvas 2D API) & jQuery 3.7.1 (DOM 제어 및 이벤트 핸들링)
- Libraries:
  - JSZip (v3.10.1): 브라우저 내 메모리 기반 비동기 ZIP 아카이브 생성
  - FileSaver.js (v2.0.5): 브라우저 로컬 파일 시스템 다운로드 트리거
- Typography: Google Fonts (Outfit, Noto Sans KR)

## 4. 핵심 처리 메커니즘

1. 원본 해상도 보존 및 스마트 캔버스 계산:
   - 원본 유지(Origin) 옵션 사용 시, 단순 강제 업스케일링으로 인한 화질 저하를 방지합니다.
   - Padding 모드: 원본의 가로 또는 세로 중 긴 축을 유지하면서 목표 비율에 필요한 정밀 여백 크기(`targetW`, `targetH`)를 수학적으로 산출하여 고화질을 유지합니다.
   - Crop 모드: 목표 비율에 맞는 최대 사각 영역을 원본 정중앙(Center Crop)에서 추출하여 불필요한 화질 손실 없이 선명하게 출력합니다.
2. 비동기 단계별 프로그레스 UX:
   - 대용량 이미지 처리 시 브라우저 멈춤(Freezing) 현상을 방지하기 위해 비동기 프로미스 기반으로 순차/병렬 처리를 진행합니다.
   - 각 작업 상태(0% -> 15% -> 45% -> 75% -> 100%)를 시각적으로 갱신하여 직관적인 피드백을 제공합니다.
3. 옵션 실시간 동기화 (Debounced Reprocess):
   - 대기열에 이미지가 로드된 상태에서 사용자가 비율, 모드(Padding/Crop), 배경색, 해상도를 변경하면 자동으로 디바운스(Debounce) 재연산이 실행되어 별도 재업로드 없이 즉각 새로운 결과물을 생성합니다.

## 5. 실행 방법

1. 본 애플리케이션은 순수 클라이언트 사이드 기술로 구현되어 별도의 서버 설치나 빌드 과정 없이 동작합니다.
2. `recipe07/index.html` 또는 프로젝트 루트의 `index.html`을 크롬(Chrome), 엣지(Edge), 사파리(Safari), 파이어폭스(Firefox) 등 모던 웹 브라우저에서 직접 실행하여 즉시 사용할 수 있습니다.
