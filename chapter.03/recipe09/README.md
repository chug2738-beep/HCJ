# Smart GIF Studio

**Smart GIF Studio**는 브라우저에서 서버로의 데이터 전송 없이 안심하고 GIF 파일(리사이징, 다운스케일, 크롭, FPS 조절 등)을 편집할 수 있는 클라이언트 사이드 웹 애플리케이션입니다.

---

## 🌟 주요 특징

1. **완벽한 프라이버시 보장**: 업로드된 모든 GIF 파일은 사용자의 브라우저 내에서만 처리되며, 외부 서버로 전송되지 않습니다.
2. **반응형 레이아웃**:
   - **데스크톱 (769px 이상)**: 좌측 GIF 미리보기 / 우측 편집 패널 배치
   - **모바일 (768px 이하)**: 상단 GIF 미리보기 / 하단 편집 패널 배치
3. **간편한 파일 업로드**: 드래그 앤 드롭 및 파일 탐색기 기반 업로드 지원
