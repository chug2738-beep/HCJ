# smart QR - 웹 기반 스마트 QR 코드 생성 솔루션

사용자가 입력한 URL을 바탕으로 실시간으로 고화질 QR 코드를 생성하고, 손쉽게 JPG 이미지 파일로 다운로드할 수 있는 반응형 웹 애플리케이션입니다.

## 1. 프로젝트 개요

- **프로젝트명**: smart QR
- **역할**: 전문 웹 퍼블리셔 가이드 및 웹 애플리케이션 구축
- **핵심 목표**: 브랜드 로고와 조화를 이루는 따뜻하고 화사한 비주얼과 직관적인 마우스 인터랙션을 제공하는 고품질 QR 코드 생성 솔루션

## 2. 폴더 구조

```text
chapter.03/
├── assets/
│   ├── css/
│   │   └── style.css       # 웜톤 파스텔 테마 및 마우스 반응형 그라데이션 스타일시트
│   ├── js/
│   │   └── script.js       # 마우스 선형 보간 모션, QR 생성 및 JPG 다운로드 스크립트
│   └── img/
│       └── logo.png        # 상단 좌측 브랜드 로고 이미지
├── index.html              # 시맨틱 웹 표준 마크업 메인 파일
└── README.md               # 프로젝트 매뉴얼 및 가이드 문서
```

## 3. 기술 스택 및 라이브러리

- **HTML5**: 시맨틱 웹 표준 준수 마크업, 웹 접근성(ARIA) 지원
- **CSS3**: 
  - 브랜드 로고 맞춤형 웜 피치 & 앰버 선셋(Sunset Amber & Peach) 컬러 팔레트
  - 글래스모피즘(Glassmorphism) 카드 및 입력창 UI
  - 다중 방사형 그라데이션(Multi Radial Gradient)과 동적 색조 회전(`hue-rotate`)
- **JavaScript (ES6+)**:
  - `requestAnimationFrame`과 선형 보간(lerp)을 결합한 유기적 마우스 추종 배경 모션
  - DOM 인터랙션 및 QR 생성 트랜지션 제어
  - HTML5 Canvas API 기반 순백색 배경 합성 및 무손실 JPG 다운로드
- **QRCode.js**: 클라이언트 단에서 실시간 QR 코드를 고속 생성하는 경량 라이브러리 (CDN 로드)

## 4. 디자인 및 주요 기능

1. **로고 맞춤형 브라이트 웜톤 디자인**:
   - 로고의 캐릭터 및 폰트 톤과 어울리도록 따뜻한 아이보리 크림 베이스 위에 앰버, 피치, 코랄 그라데이션을 조화롭게 배색
2. **마우스 인터랙티브 유기적 그라데이션**:
   - 마우스 커서의 움직임에 따라 여러 겹의 빛(광원)이 부드럽게 위치를 이동
   - 커서 좌표에 비례하여 색조(Hue)가 미세하고 우아하게 전환되어 신비롭고 화사한 분위기 연출
3. **직관적인 모션 인터랙션**:
   - 화면 중앙의 심플 입력창에 URL 입력 후 엔터나 버튼 클릭 시 입력창이 화면 하단으로 부드럽게 슬라이드 다운
   - 화면 정중앙에 선명한 QR 코드가 입체적인 카드 형태로 페이드인
4. **고품질 JPG 다운로드**:
   - QR 코드 클릭 시 오프스크린 Canvas를 통해 투명 영역을 순백색으로 채워 왜곡 없는 고품질 320x320 JPG(`smart-qr-code.jpg`) 파일로 원클릭 저장

## 5. 사용 방법

1. 브라우저에서 `index.html` 파일을 엽니다.
2. 중앙의 입력 필드에 원하는 URL을 입력합니다. (예: `https://example.com`)
3. 우측 화살표 버튼을 클릭하거나 Enter 키를 누릅니다.
4. 마우스를 화면 곳곳으로 움직이며 은은하게 변화하는 웜톤 배경 그라데이션을 감상합니다.
5. 중앙에 생성된 QR 코드나 하단 버튼을 클릭하여 `smart-qr-code.jpg`로 저장합니다.
