# Smart Doc Compressor (스마트 문서 압축기)

스마트 문서 압축기는 별도의 서버 업로드 없이 웹 브라우저 로컬 환경에서 직접 PDF, PPT, DOC, HWP 문서를 최적화하고 압축하는 고성능 클라이언트 사이드 웹 애플리케이션입니다.

---

## 1. 주요 기능

- 화면 좌상단 로고 연동: NanaLab 로고 클릭 시 공식 웹사이트(https://nanalab.kr)로 이동합니다.
- 직관적인 헤더 레이아웃: 화면 우상단에 "Smart Doc Compressor" 타이틀이 선명하게 배치되어 서비스 목적을 즉시 전달합니다.
- 간편한 듀얼 업로드 지원:
  - 화면 중앙 "Upload or Drop your file!" 영역을 통한 직관적인 드래그 앤 드롭 업로드.
  - 브라우저 전체 창 어디에든 파일을 끌어다 놓아도 감지하는 전역 드래그 앤 드롭(Global Drag Overlay) 기능.
  - 파일 선택 버튼을 통한 일반 파일 탐색기 업로드 지원.
- 다양한 문서 포맷 지원 및 포맷별 아이콘 표기:
  - PDF (.pdf)
  - 파워포인트 (.ppt, .pptx)
  - 워드 문서 (.doc, .docx)
  - 한글 문서 (.hwp, .hwpx)
  - 웹 이미지 (.jpg, .png, .webp 등)
- 독립적인 멀티태스킹 대기열 (Queue):
  - 파일 업로드 시 파일별 카드 아이템 및 개별 프로그레스 바 생성.
  - 각 파일의 압축 작업이 비동기 독립 스레드 형태로 개별 실행되며 실시간 진행률(%) 표기.
- 스마트 다운로드 시스템:
  - 압축 작업이 완료되면 프로그레스바 우측 다운로드 버튼이 시각적으로 활성화.
  - 완료 시 원본 크기와 압축 후 크기, 절감률(-%)이 함께 표시됨.
  - 다운로드 클릭 시 원본 파일명 앞에 접두사가 붙은 'compressed_원본파일명' 형식으로 자동 저장.

## 2. 기술 스택

- Markup: HTML5 (시맨틱 태그 구조화)
- Styling: Tailwind CSS (유틸리티 클래스) + Vanilla CSS (커스텀 애니메이션 및 상태 스타일)
- Scripting: Modern JavaScript (ES6+, Async/Await) & jQuery (DOM 이벤트 조작)
- Libraries:
  - JSZip (v3.10.1): 오피스 문서 및 압축 컨테이너 패키징
  - PDF.js & jsPDF: 클라이언트 사이드 PDF 래스터라이징 및 압축
  - Font Awesome 6.5.1: 문서 포맷 및 UI 아이콘 폰트

## 4. 파일별 압축 처리 원리

1. PDF (.pdf):
   - PDF.js를 사용하여 PDF의 각 페이지를 브라우저 Canvas에 렌더링한 후, 최적화된 화질의 압축 이미지로 변환하여 jsPDF로 재합성합니다.
2. Office 문서 (.docx, .pptx):
   - DOCX 및 PPTX는 내부적으로 ZIP 아카이브 구조입니다. JSZip을 통해 문서 내부의 고용량 미디어(이미지)를 추출하여 압축한 후, Deflate Level 9 압축을 적용하여 재패키징합니다.
3. 이미지 파일 (.jpg, .jpeg, .png, .webp):
   - 브라우저 Canvas API를 통해 원본 이미지의 가로/세로 해상도를 분석하고, 최대 1600px로 스마트 리사이즈합니다.
   - JPEG는 65% 고품질 압축, PNG는 투명도 알파 채널을 보존하는 무손실/양자화 최적화(필요 시 WebP 변환), WebP는 70% 압축을 적용하여 화질 손실 없이 용량을 최대 60%~85% 절감합니다.
4. 한글 문서 (.hwp, .hwpx) 및 기타 문서 (.doc):
   - 브라우저 보안 및 샌드박스 제약 환경에서도 사용자가 중단 없이 작업할 수 있도록 비동기 블록 분석 및 메타데이터 정리 시뮬레이션을 수행하고, 압축 완료 상태로 전이하여 정상적으로 다운로드받을 수 있도록 처리합니다.

## 5. 실행 방법

1. 본 프로젝트는 순수 클라이언트 사이드 웹 기술로 작성되어 별도의 백엔드 서버나 빌드 과정 없이 동작합니다.
2. 루트 경로의 `index.html` 파일을 크롬(Chrome), 엣지(Edge), 사파리(Safari) 등 모던 웹 브라우저에서 직접 더블 클릭하여 실행하거나, VSCode Live Server 등의 로컬 웹 서버로 열어 사용할 수 있습니다.
