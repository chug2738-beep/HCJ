# Video to GIF (비디오 to GIF 애니메이션 변환기)

Video to GIF는 사용자가 업로드한 동영상(MP4, WebM, MOV 등)을 별도의 서버 업로드 없이 브라우저 내에서 직접 프레임 단위로 추출(29FPS 제한)하여 가볍고 부드러운 GIF 애니메이션으로 변환하는 고성능 클라이언트 사이드 웹 애플리케이션입니다.

---

## 1. 주요 기능 및 요구사항 구현 내용

1. 상단 좌측 로고 연동:
   - 화면 좌상단에 `logo.png` 로고가 배치되어 있으며, 로고 클릭 시 공식 웹사이트(https://nanalab.kr)로 이동합니다.
2. 상단 우측 서비스 타이틀:
   - 화면 우상단에 "video to GIF" 명칭과 함께 29 FPS Converter 배지를 배치했습니다.
3. 메인 대형 타이틀:
   - 메인 중앙에 `video→GIF` 텍스트를 크고 선명하게 배치했습니다.
4. 서브 슬로건 문구:
   - `Make your own GIF Animation!` 슬로건과 100% 브라우저 로컬 안전 안내를 제공합니다.
5. 직관적인 중앙 업로드 메뉴:
   - 화면 중앙의 대형 점선 드롭 존을 통해 동영상 파일을 드래그 앤 드롭하거나, "동영상 파일 선택하기" 버튼을 눌러 직접 탐색기에서 파일을 업로드할 수 있습니다.
6. 대기열 파일 목록 & 스마트 다운로드:
   - 파일 업로드 시 하단에 작업 대기열 카드가 생성됩니다.
   - 좌측: 동영상의 0초 프레임을 캡처한 썸네일 미리보기 제공
   - 중앙: 파일명, 영상 규격 배지, 실시간 프로그레스 바(0% -> 100%), 상태 메시지 표시
   - 우측: 프로그레스 바가 100%에 도달하면 다운로드 버튼이 활성화되어 클릭 시 즉시 GIF 파일을 다운로드할 수 있습니다.
7. 동영상 프레임 슬라이싱 및 GIF 애니메이션 생성:
   - HTML5 Video와 Canvas 2D API를 연동하여 동영상의 시점을 순차적으로 탐색(Seek)하고 프레임을 캡처하여 GIF 프레임으로 합성합니다.
8. 29FPS 프레임 레이트 제한:
   - 브라우저 성능 최적화 및 렌더링 지연을 방지하기 위해 엄격한 29FPS(`interval = 1 / 29`) 프레임 추출을 적용했습니다.

---

## 2. 기술 스택

- Markup: HTML5 (시맨틱 태그 구조화)
- Styling: Tailwind CSS CDN + Vanilla CSS (CSS Grid, Flexbox, 커스텀 쉬머 애니메이션, 체커보드 패턴)
- Scripting: Modern JavaScript (ES6+, Async/Await, Canvas 2D API, Web Workers) & jQuery 3.7.1
- Libraries:
  - gif.js (v0.2.0): 브라우저 내 다중 Web Worker 기반 고성능 GIF 인코딩
  - Font Awesome 6.5.1: 고화질 벡터 UI 아이콘 (이모지 대체)
- Typography: Google Fonts (Outfit, Noto Sans KR)

## 4. 핵심 처리 원리

1. 정밀 29FPS 프레임 슬라이싱:
   - `currentTime`을 `0`부터 비디오 전체 길이(`duration`)까지 `1 / 29`초 간격으로 점진 이동시키며, `seeked` 비동기 이벤트를 대기한 후 캔버스에 프레임을 렌더링합니다.
   - 프레임마다 `delay = Math.round(1000 / 29)` ms를 부여하여 29FPS의 자연스러운 재생 속도를 보장합니다.
2. 2단계 실시간 프로그레스 바:
   - 전반부 (0% ~ 50%): 비디오 프레임 추출 및 캔버스 캡처 진행률 실시간 반영
   - 후반부 (50% ~ 100%): gif.js 백그라운드 Web Worker 인코딩 진행률 실시간 연동
   - 100% 도달 즉시 `URL.createObjectURL`을 통해 Blob 다운로드 링크 활성화
3. Web Worker 인라인 로딩 (CORS 프리):
   - 로컬 `file:///` 경로 또는 웹서버 환경에서 발생할 수 있는 크로스 도메인 Web Worker 차단 이슈를 방지하기 위해 `Blob URL` 기반 인라인 워커 스크립트를 적용하여 무설치 단독 실행을 지원합니다.
4. 해상도 스마트 최적화:
   - 가로폭 최대 480px 기준으로 종횡비를 유지하며 스마트 리사이즈하여 대용량 고해상도 비디오에서도 빠르고 쾌적하게 GIF를 생성합니다.

## 5. 실행 방법

1. 본 애플리케이션은 순수 클라이언트 사이드 기술로 작성되어 별도의 백엔드 서버나 빌드 과정 없이 동작합니다.
2. `recipe08/index.html` 파일을 크롬(Chrome), 엣지(Edge), 사파리(Safari), 파이어폭스(Firefox) 등 모던 웹 브라우저에서 직접 더블 클릭하여 실행하거나, 로컬 웹 서버로 열어 사용할 수 있습니다.
