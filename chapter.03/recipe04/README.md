# 모바일 청첩장 웹 애플리케이션 퍼블리싱 가이드

본 프로젝트는 스마트폰 접속을 최우선으로 고려하여 제작된 고품질 모바일 청첩장 웹 애플리케이션입니다.
현업 10년차 웹 퍼블리셔이자 튜터의 관점에서 실무 표준 마크업, CSS 인터랙션 기법, 바닐라 자바스크립트 기반의 동적 기능을 체계적으로 설계하였습니다.

---

## 1. 프로젝트 개요

- 프로젝트명: 드미트리 & 로렐라이 모바일 청첩장
- 주요 기능:
  - 스마트폰(모바일) 환경 전제 레이아웃 (최대 폭 440px 뷰포트 래핑 및 세이프 에리어 지원)
  - 제공된 기획 문구(문구.txt) 및 인물/스튜디오 사진 완벽 연동
  - 결혼식 목표 일시(2099.12.26 12:00) 기준 실시간 플립(Flip) 카운트다운 애니메이션
  - 신랑/신부 연락처 액션 시트 모달 (전화 걸기 / 문자 전송 분기)
  - 마음 전하시는 곳(신랑측/신부측) 아코디언 및 원클릭 계좌번호 복사(토스트 팝업 알림)
  - 갤러리 이미지 라이트박스 풀스크린 확대 모달
  - 로컬스토리지(LocalStorage) 연동 실시간 축하 메시지 방명록
  - 모바일 링크 공유(Web Share API 및 클립보드 복사 폴백)

## 3. 기술 스택 및 환경

- 마크업: HTML5 (W3C 웹 표준 및 시맨틱 구조 준수)
- 스타일링: CSS3 (CSS Variables, Flexbox, CSS Grid, 3D Transform, Keyframes Animation)
- 스크립트: Vanilla JavaScript (ES6+, 외부 의존성 없는 가벼운 로딩)
- 폰트: Google Fonts (Nanum Myeongjo, Gowun Dodum, Playfair Display, Cormorant Garamond)
- 호환성: iOS Safari, Android Chrome, 삼성 인터넷, 최신 데스크톱 브라우저

## 4. 튜터가 전하는 핵심 퍼블리싱 강의 노트

### 4.1. 모바일 퍼스트 뷰포트 레이아웃 설계
모바일 청첩장은 95% 이상의 사용자가 카카오톡이나 모바일 메신저 인앱 브라우저를 통해 접속합니다.
- `viewport-fit=cover`: 아이폰 노치 영역 및 하단 홈 바 영역까지 자연스럽게 여백을 처리합니다.
- `.mobile-wrapper`: 가로폭을 `max-width: 440px`로 제한하고 `margin: 0 auto`로 중앙 배치하여 모바일 기기에서는 100% 꽉 찬 네이티브 앱 느낌을 제공하며, PC 접속 시에는 품격 있는 모바일 카드 룩을 완성합니다.
- `calc(40px + env(safe-area-inset-bottom))`: 하단 제스처 바와의 간섭을 예방합니다.

### 4.2. 실시간 카운트다운 및 플립(Flip) 애니메이션 메커니즘
목표 시점(2099년 12월 26일 12시 KST)과 현재 시점(`new Date().getTime()`)의 타임스탬프 차이를 1,000ms마다 연산합니다.
- 값이 이전 초와 다를 때만 DOM을 갱신합니다.
- CSS 펄스 애니메이션(`.animate-flip`)을 재트리거하기 위해 자바스크립트에서 `void card.offsetWidth;`를 호출하여 브라우저의 DOM Reflow를 유도함으로써 매초 자연스럽게 카드가 튀어 오르는 시각적 리듬감을 부여했습니다.

### 4.3. 신뢰성 높은 클립보드 복사(Clipboard API + Fallback)
모바일 브라우저(특히 인앱 브라우저 및 HTTP 환경)에서는 `navigator.clipboard` 객체가 차단될 수 있습니다.
- 1차: 최신 비동기 API인 `navigator.clipboard.writeText()` 시도
- 2차(폴백): 숨김 처리된 `<textarea>`를 동적으로 생성한 뒤 `document.execCommand('copy')`를 실행하여 모든 모바일 기기에서 예외 없이 복사가 동작하도록 보장했습니다.
- 복사 완료 시 시각적으로 명확한 피드백을 주기 위해 커스텀 토스트 알림창을 노출합니다.

### 4.4. 퍼포먼스 최적화 스크롤 리빌 (Intersection Observer)
과거 `scroll` 이벤트 리스너 방식은 메인 스레드에 부담을 주어 스크롤 버벅임(Jank) 현상을 유발합니다.
이를 방지하기 위해 `IntersectionObserver`를 도입하여 요소가 뷰포트 영역에 12% 진입할 때만 `.revealed` 클래스를 부여하고 감시를 해제(`unobserve`)하여 모바일 기기의 배터리와 CPU 자원을 절약했습니다.
