# 추연승 포트폴리오

[`../0727`](../0727) 템플릿을 기반으로 본인(추연승)의 정보로 커스터마이징한 개인 포트폴리오 페이지입니다.

## 구성
- `index.html` — Intro / About / Project / Contact 섹션과 취미·성격 모달로 구성
- `index.js` — 모달 열기/닫기, 타이핑 효과, 스크롤 진행바
- `style/` — `reset.css`, `style.css`
- `src/font/` — Gmarket Sans 웹폰트
- `src/img/` — 프로필/소개/프로젝트 이미지, 아이콘

## 기술 스택
- HTML5, CSS3, Vanilla JavaScript

## 실행 방법
`index.html`을 브라우저로 열면 바로 확인할 수 있습니다.
