# K-TRIP KOREA | 日本人向け韓国観光ガイド ウェブパブリッシング

## 1. プロジェクト概要
- プロジェクト名: K-TRIP KOREA (韓国公式旅行ガイド)
- ターゲット: 韓国旅行を計画・検討中の日本人個人旅行者(FIT)、2030世代およびファミリー層
- 目的: 最新トレンド(聖水洞カフェ、オリーブヤング、K-POP)から伝統遺産(景福宮、北村韓屋村)、実用的な決済・交通情報(WOWPASS、気候同行カード)までを網羅した高品位なレスポンシブWebページの構築

## 4. 10年目シニアパブリッシャーによる設計・実装のポイント

### (1) セマンティックマークアップとアクセシビリティ
- ページの構造を `header`, `nav`, `main`, `section`, `article`, `footer` で論理的に分割。
- 各ボタンやフォーム要素に適切な `aria-label`, `aria-expanded` を設定し、スクリーンリーダー環境やキーボード操作にも配慮。
- 見出し階層 (`h1` -> `h2` -> `h3`) を厳格に保持し、SEOスコアの最大化を図りました。

### (2) Tailwind CSS と カスタムCSSのシナジー
- レイアウトやスペーシングには Tailwind CSS のユーティリティクラスを活用し、トークン消費とCSSファイル容量を抑制。
- グラスモフィズム (`backdrop-filter`)、繊細なホバーアニメーション (`cubic-bezier` トランジション)、カードの立体感などは `assets/css/style.css` に分離してカプセル化。

### (3) jQueryによる軽量で直感的なインタラクション
- カテゴリ別フィルタリング: `data-filter` 属性と jQuery の `fadeIn()`, `fadeOut()` を組み合わせ、スムーズな表示切り替えを実現。
- 為替計算機ウィジェット: `input` イベントを監視し、日本人旅行者が最も気になる円・ウォン換算をリアルタイムに計算。
- ブックマーク機能: 状態トグル (`.active`) とバッジカウントの連動。

## 5. 実務で役立つ無料テスト画像・アセット提供サイト一覧

Webパブリッシングの実務やプロトタイプ制作において、ライセンスフリーで高品質なテスト画像を取得できるおすすめサイトです。

1. **Unsplash (https://unsplash.com/)**
   - 特徴: 世界中のクリエイターが高解像度の写真を無償提供。
   - 活用法: `https://images.unsplash.com/photo-...` のURLパラメーター (`auto=format&fit=crop&w=800&q=80`) を用いて、軽量化されたWebP形式や任意サイズで画像を取得可能。
   - 今回のプロジェクトでも、ソウル夜景・景福宮・カフェ・済州島の美しい写真に採用しています。

2. **Picsum Photos (https://picsum.photos/)**
   - 特徴: プレースホルダー画像に最も手軽なサービス。
   - 活用法: `<img src="https://picsum.photos/800/600" alt="ダミー">` のようにURLへ幅と高さを指定するだけでランダムな実写画像を取得可能。

3. **Pexels (https://www.pexels.com/)**
   - 特徴: 高品質な写真だけでなく、無料の背景動画(MP4)素材も豊富。
   - 活用法: ヒーローセクションの背景動画テストやライフスタイル訴求に最適。

4. **Pixabay (https://pixabay.com/)**
   - 特徴: 写真に加え、イラストやベクター素材も多数提供。日本語検索の精度が高い。

5. **SVG Repo (https://www.svgrepo.com/)**
   - 特徴: 50万点以上の商用無料SVGベクターアイコンを提供。
   - 活用法: UIアイコン(矢印、星、マップピン、ハート等)をインラインSVGとして直接HTMLに埋め込む際に便利。
