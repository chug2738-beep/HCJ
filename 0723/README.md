# 추연승 엔지니어링 포트폴리오

기계공학/CAE(해석·시뮬레이션) 엔지니어를 소개하는 단일 페이지 포트폴리오입니다.

## 구성
- `index.html` — 소개, 기술 스택, 프로젝트, 연락처 섹션으로 구성된 정적 HTML 페이지
- `catia_model.png` — CATIA 3D 모델링 이미지 (의자 하중·변형 해석 프로젝트)
- `cfd_simulation.jpg` — STAR-CCM+ CFD 시뮬레이션 이미지 (차량 공력 최적화 프로젝트)
- `working.mp4` — 자작차 동아리 실주행 영상
- `profile.jpg` — 프로필 사진

## 기술 스택
- HTML (별도 CSS/JS 없이 브라우저 기본 스타일 사용)
- 소개된 엔지니어링 도구: CATIA, Abaqus, Simcenter STAR-CCM+, Python, Linux(Ubuntu)

## 실행 방법
`index.html`을 브라우저로 열면 바로 확인할 수 있습니다.
